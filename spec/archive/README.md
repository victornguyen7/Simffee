# Archive

Status reports and finished plans from the hackathon build. They describe how the project got
here, not how it works now, so they are kept for history only and may contradict the current code
(for example, they describe the xAI transport that was later replaced by Groq).

| Document | What it was |
| --- | --- |
| [B1_STATUS.md](B1_STATUS.md), [B2_STATUS.md](B2_STATUS.md) | Status reports for backend milestones B1 and B2 |
| [CHANGE_REPORT.md](CHANGE_REPORT.md), [PHASE_B_REPORT.md](PHASE_B_REPORT.md) | Change reports for earlier rounds of work |
| [FIX_PLAN.md](FIX_PLAN.md), [RUN_PLAN.md](RUN_PLAN.md), [COST_PLAN.md](COST_PLAN.md), [ELASTIC_PLAN.md](ELASTIC_PLAN.md) | Plans that were carried out |

Code comments still cite some of these by section label (e.g. "RUN_PLAN D2"); the label is the
heading to search for here.

The current documents are [SPEC.md](../SPEC.md) and [SPEC_FUNCTIONAL.md](../SPEC_FUNCTIONAL.md)
(how the simulation works), [BACKEND_PLAN.md](../BACKEND_PLAN.md) and [ROADMAP.md](../ROADMAP.md)
(cited throughout the code by section), and [AUDIT_FIX_PLAN.md](../AUDIT_FIX_PLAN.md) (the
current audit and fixes).
